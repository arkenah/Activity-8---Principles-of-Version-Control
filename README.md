# Distance Formula Calculator

## Description
This program calculates the distance between two points using the distance formula.

## How to Run
1. Open this Project Folder (PythonProject18)
2. Click this README.md
3. Enter x1
4. Enter y1
5. Enter x2
6. Enter y2
7. See the calculated distance between the two points

## Inputs Needed
* Position of x1
* Position of y1
* Position of x2
* Position of y2

## Sample Output
* Enter x1: 2
* Enter y1: 3
* Enter x2: 7
* Enter y2: 8

* The distance between the two points is: 7.07
